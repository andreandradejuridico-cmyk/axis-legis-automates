# Project: Axis Legis Automates

## Vision
A premium "Boutique de Tecnologia Jurídica" platform that automates the intake process for law firms using AI, WhatsApp integration, and a sophisticated scheduling system.

## Brand & Aesthetics
- **Core Colors:** Navy (#1a2b3c), Bronze (#a67c52), Charcoal (#1a1c23), Silver (#c0c0c0).
- **Typography:** Serif headings for elegance, Sans-serif for clarity.
- **UI Principles:** Sidebar-based navigation, glassmorphism, premium shadows, and smooth transitions.

## Tech Stack
- **Frontend:** React, Vite, Tailwind CSS, Framer Motion, Shadcn UI.
- **Backend:** Supabase (Auth, PostgreSQL, RLS, Edge Functions).
- **External:** Evolution API (WhatsApp), Resend/SendGrid (Email).

## Core Modules
1. **Admin Dashboard:** Premium control panel for staff.
2. **AI Agent (Socrative):** Lead qualification and automated intake.
3. **Appointment System:** Custom scheduling with availability checks.
4. **Notification Engine:** Automated reminders via WhatsApp & Email.
